# 题目、尺规工具与输出

## 1. 给定信息

给定欧氏平面内不共线的三点 $A,B,C$。三点互异，三角形面积为正，三个内角均严格介于 $0^\circ$ 与 $180^\circ$ 之间。

输入可以顺时针或逆时针排列，可以任意平移、旋转、反射及正比例缩放。初始对象只有三个给定点。连接两点所得的边线属于实际作图。

## 2. 最终目标

输出一个点 $P$，满足对平面上每一点 $Q$ 都有

$$PA+PB+PC\le QA+QB+QC.$$

若等号成立，则必须有 $Q=P$。因此每个合法输入恰有一个输出点。

允许 $P$ 为已有顶点。某角达到或超过 $120^\circ$ 时，输出该角顶点即可完成题目。

## 3. 基础尺规操作

采用无刻度直尺和塌圆规，与前几题保持一致。

1. 经过两个已有的不同点作直线。
2. 以已有点为圆心、经过另一个已有点作圆。
3. 取得已作直线与圆、两个圆、两条直线的有限实交点。
4. 根据精确点线位置关系选择交点和分支。

本题的完整流程只需上述操作。每个圆都由圆心与过圆点给出，每条直线都由两个已有不同点给出。

## 4. 精确关系判断

使用点相等、点相对于直线的同侧或异侧、射线方向、点位于圆内或圆上或圆外等关系。

圆内外比较等价于比较圆心至该点的距离与圆半径。若需将其表述为直线次序，连接圆心与待测点，取相应射线和圆的交点，比较二点在射线上的先后次序。待测点恰为圆心时，直接判为圆内。

判角步骤用同一个圆上两条弦的长度关系，将 $120^\circ$ 比较化为点相对于另一个已作圆的位置关系。精确相等对应临界角，完整展开见 [ANSWER](ANSWER.md)。

## 5. 分支与范围

| 分支 | 条件 | 输出 |
|---|---|---|
| 顶点分支 | 某个内角 $\ge120^\circ$ | 该顶点 |
| 内部分支 | 所有内角 $<120^\circ$ | 两个外作等边三角形对应连接线的交点 |

三角形内角和为 $180^\circ$，所以顶点分支的顶点唯一。相等情形归入顶点分支。

等边、等腰、直角、钝角及邻近 $120^\circ$ 的三角形全部按相同规则处理。每个钝角三角形仍须判断其最大角是否达到 $120^\circ$。

题面保持不共线三点。证明中的目标函数定义在整个平面，候选点允许位于三角形内、边界或外部。

## 6. 证明与动画数据

一般证明适用于任意实坐标输入。证明中使用连续性、欧氏范数的严格凸性条件及距离函数的一阶变化，另以 $60^\circ$ 旋转给出全平面几何下界和达到下界的条件。

动画采用已检查的实代数坐标，显示数据由 SageMath 的精确实代数数域 `AA` 生成。浮点数只用于 Manim 绘制，分支与交点关联在导出前精确检查。
