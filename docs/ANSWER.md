# 费马—托里拆利点的完整尺规作法

## 1. 初始对象与作图安排

已有不共线三点 $A,B,C$。先连接 $AB,BC,CA$。

先对内角作精确分类，再在三个内角均小于 $120^\circ$ 的分支中完成外作等边三角形的构造。整个流程适用于顺时针和逆时针的输入编号，所有“外侧”均由第三个顶点相对于边线的异侧关系确定。[题面与工具](DESIGN.md)

## 2. 用圆比较一个内角与 $120^\circ$

先对一般角 $\angle UVW$ 给出固定步骤，其中 $V$ 是待检查的顶点，$U,W$ 是其余两个给定点。三点不共线，所以 $W$ 严格位于直线 $VU$ 的某一侧。

### 2.1 将两条角边截成等长

1. 以 $V$ 为圆心、经过 $U$ 作圆 $\omega$。
2. 取射线 $VW$ 与 $\omega$ 的交点 $T$。

有 $VT=VU>0$。直线 $VW$ 经过圆心，两个交点分别位于相反射线上，因而 $T$ 由射线方向唯一确定。允许 $T=W$。

### 2.2 作出同侧的 $120^\circ$ 参考射线

3. 以 $U$ 为圆心、经过 $V$ 作圆 $\eta$。
4. 取 $\omega,\eta$ 的两个交点，选择与 $W$ 位于直线 $VU$ 异侧的交点 $K$。
5. 连接 $V,K$，取这条直线与 $\omega$ 的另一个交点 $H$，即与 $K$ 关于 $V$ 相对的交点。

$VUK$ 为等边三角形。$VK$ 与 $VU$ 成 $60^\circ$，且 $K$ 位于 $W$ 的异侧。反向射线 $VH$ 位于 $W$ 的同侧，满足

$$\angle UVH=120^\circ.$$

两圆的圆心距和半径均为 $VU$，它们始终有两个不同交点。$H$ 是圆上 $K$ 的对径点，且 $V,H,K$ 两两不同。

### 2.3 用圆内外关系决定分支

6. 以 $U$ 为圆心、经过 $H$ 作圆 $\sigma$。
7. 判断 $T$ 相对于 $\sigma$ 的位置。

| 位置关系 | 内角大小 |
|---|---|
| $T$ 在 $\sigma$ 内 | $\angle UVW<120^\circ$ |
| $T$ 在 $\sigma$ 上 | $\angle UVW=120^\circ$ |
| $T$ 在 $\sigma$ 外 | $\angle UVW>120^\circ$ |

临界角下 $T=H$，直接复用这个交点即可。后续圆仍有正半径，分支由“圆上”关系确定。

理由是 $U,T,H$ 都在以 $V$ 为圆心的圆 $\omega$ 上，且 $T,H$ 位于直线 $VU$ 的同一侧。这个开半圆内，弦 $UT$ 随圆心角 $\angle UVT$ 从 $0^\circ$ 到 $180^\circ$ 严格增加。参考弦为 $UH$，所以比较 $UT$ 与 $UH$ 就能完成判角。

用余弦定理核对，若 $r=VU$、$\theta=\angle UVW$，则

$$UT^2=2r^2(1-\cos\theta),\qquad UH^2=3r^2.$$

故 $UT^2- UH^2$ 的符号与 $\theta-120^\circ$ 的符号相同。作图执行使用上表的圆内外关系。

## 3. 检查三个内角

依次将上节的 $(V,U,W)$ 取为

$$ (A,B,C),\qquad (B,C,A),\qquad (C,A,B).$$

1. 如果检查到某角等于或大于 $120^\circ$，立即输出该角顶点，作图完成。
2. 如果三个角均小于 $120^\circ$，进入第 4 节。

三角形至多有一个角达到 $120^\circ$，因此先后次序不影响输出。最多进行三次相同的有限判角程序。

第一轮判角已经作出 $AB$ 外侧的等边顶点 $K$，记为 $D$。第二轮已经作出 $BC$ 外侧的等边顶点，记为 $E$。在内部分支中可以直接复用这两个点。

## 4. 外作两个等边三角形

以下单独列出两个点的取得，便于与动画和经典作法对照。

### 4.1 在 $AB$ 外侧取得 $D$

1. 作以 $A$ 为圆心、经过 $B$ 的圆。
2. 作以 $B$ 为圆心、经过 $A$ 的圆。
3. 取两圆交点中与 $C$ 位于直线 $AB$ 异侧的点 $D$。
4. 连接 $A,D$ 与 $B,D$，得到等边三角形 $ABD$。

满足

$$AD=BD=AB.$$

### 4.2 在 $BC$ 外侧取得 $E$

1. 作以 $B$ 为圆心、经过 $C$ 的圆。
2. 作以 $C$ 为圆心、经过 $B$ 的圆。
3. 取两圆交点中与 $A$ 位于直线 $BC$ 异侧的点 $E$。
4. 连接 $B,E$ 与 $C,E$，得到等边三角形 $BCE$。

满足

$$BE=CE=BC.$$

两个等边三角形均与原三角形位于相应边线的两侧。输入顺序翻转时，异侧规则会相应翻转。

## 5. 取得并输出最小点

1. 连接 $C,D$，得到直线 $d$。
2. 连接 $A,E$，得到直线 $e$。
3. 取交点

$$P=d\cap e.$$

4. 输出 $P$。为展示目标距离，可再连接 $PA,PB,PC$。

三个角均小于 $120^\circ$ 时，$d,e$ 始终为两条不同的相交直线，且 $P$ 严格位于三角形内部。同时

$$P\in\operatorname{relint}(CD),\qquad
P\in\operatorname{relint}(AE),$$

$$\angle APB=\angle BPC=\angle CPA=120^\circ.$$

在全平面上都有

$$QA+QB+QC\ge PA+PB+PC,$$

且等号当且仅当 $Q=P$。[存在性、选点与最小性证明](PROOF.md)

## 6. 一个完整的内部精确案例

取

$$A=(0,0),\qquad B=(4,0),\qquad C=(1,3).$$

三个内角均小于 $120^\circ$。两个外作等边顶点为

$$D=(2,-2\sqrt3),$$

$$E=\left(\frac52+\frac{3\sqrt3}{2},\ \frac32+\frac{3\sqrt3}{2}\right).$$

直线 $AE$ 经过原点。直线 $CD$ 可用参数表示为

$$C+t(D-C)=(1+t,\ 3-t(3+2\sqrt3)).$$

联立两条直线得到

$$P=\left(\frac{10+4\sqrt3}{13},\ \frac{24-6\sqrt3}{13}\right).$$

三个距离之和为

$$PA+PB+PC=CD=\sqrt{22+12\sqrt3}.$$

数值约为 $P=(1.30217,1.04675)$，最小距离和约为 $6.54099$。上述数值仅用于阅读图形，定义和证明使用精确表达式。

## 7. 临界角与大角案例

### 7.1 恰好为 $120^\circ$

取

$$A=(0,0),\quad B=(3,0),\quad C=(-1,\sqrt3).$$

有 $AB=3$、$AC=2$，且

$$\frac{(B-A)\cdot(C-A)}{AB\,AC}=-\frac12.$$

因此 $\angle BAC=120^\circ$，输出 $P=A$，最小距离和为 $5$。其他每个平面点的距离和均严格大于 $5$。

### 7.2 大于 $120^\circ$

取

$$A=(0,0),\quad B=(3,0),\quad C=(-\sqrt3,1).$$

有 $AB=3$、$AC=2$、$\angle BAC=150^\circ$。输出仍为 $P=A$，最小距离和为 $5$。

## 8. 对称与邻近临界输入

| 输入 | 作图结果与处理 |
|---|---|
| 等边三角形 | 两条连接线为中线，交点是共同中心，三组夹角均为 $120^\circ$ |
| 等腰且顶角小于 $120^\circ$ | 内部交点落在对称轴上，按原步骤取得 |
| 直角三角形 | 三角均小于 $120^\circ$，采用内部分支 |
| 钝角在 $90^\circ$ 与 $120^\circ$ 之间 | 仍采用内部分支 |
| 某角恰为 $120^\circ$ | 圆上判定，直接输出该顶点 |
| 某角超过 $120^\circ$ | 圆外判定，直接输出该顶点 |
| 最大角从下方趋近 $120^\circ$ | 内部点趋近对应顶点，每个严格小于的输入仍按内部规则完成 |
| 点名置换、反射、平移、旋转、缩放 | 按实际侧别选择外作等边顶点，输出作相同变换 |

精确圆上判断决定临界分支。图形显示中的像素位置和浮点容差只用于绘制。

等边输入中，作 $D$ 时另一个圆交点恰好是给定点 $C$，作 $E$ 时另一个交点恰好是给定点 $A$。这些已有交点可以直接复用，异侧交点仍然唯一。等腰输入中的轴上重合关系也保持相同选点规则。

## 9. 有限性与可复现性

判角最多三轮，每轮包括三个正半径圆、一条连接对径点所需的直线及有限求交。后续只需两个等边顶点和两条连接线。已作点、圆、边线可重复使用。

每个异侧选择都有唯一候选，每个射线选择都有唯一候选。内部分支中的最终两条直线相交且不同，其证明见 [PROOF](PROOF.md#7-两条构造线的存在与唯一交点)。

动画的数据生成脚本按圆交点取得外作等边顶点，并检查上述三个精确案例、边角关系及旋转下界的等号情形。运行方式见 [动画说明](../animations/fermat/README.md)。
